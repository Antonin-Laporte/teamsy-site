# Teamsy — site web

Site vitrine de Teamsy (sites web + réservation en ligne pour restaurants indépendants) et 3 démos navigables.

## Structure

- `index.html` — page principale Teamsy
- `demos/bistrot.html` — démo « Le Chaudron » (bistrot)
- `demos/gastro.html` — démo « Maison Lavigne » (gastronomique)
- `demos/street-food.html` — démo « Bao Brothers » (street-food)

Site statique, sans dépendance ni build. Déployé sur Vercel.
